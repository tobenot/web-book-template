### 练习：写一个从 1 加到 100 的函数

练习本身就是普通 Markdown，不需要额外组件；只把答案折进 `<Solution>`。

<Solution>
```ts
function sum1to100() {
  return Array.from({ length: 100 }, (_, i) => i + 1).reduce((a, b) => a + b, 0);
}
```
</Solution>
