# 百科式补充：长期工作单

> 正文负责教学叙事（建立动机 → 带着问题动手 → 讲解原理 → 变式 → 收束）。
> 但很多概念讲过一次之后，还需要单独沉淀成可查、可索引、可回链的资料——这件事不靠改正文完成，靠附录和回链网络完成。本文件是为这件事记账。

---

## 1. 这份工作单是干什么的

正文不为术语让步：术语首次出现时用括号简单注明即可。但术语越多，读者中途跳读时越容易迷路。所以另起一套独立的「事后沉淀」，服务「读到一半想查这是什么」的需求。

按自己书的领域列一张类似下面的表，规划这本书需要哪些附录：

| 类型 | 形态 | 落地位置 |
|---|---|---|
| 术语条目 | 词条 + 极短定义 + 首次出现章节锚点 | 附录 A · 术语表 |
| （按需添加） | | |

### 不做什么

- 不为了百科化反过来改正文叙事节奏。
- 不重新发明轮子：能直接引用官方文档原文/链接，就不重写。
